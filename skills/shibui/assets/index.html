Five durable decisions

Keep task context

Keep the information and controls needed for the task available together.

Reveal on demand

Move secondary context into explicit, discoverable destinations.

Give each view a purpose

Let reading and manipulation use the structure each task needs.

Structure with space

Use proximity, alignment, and type before surfaces or rules.

Draw meaning

Show a container only when its boundary communicates something.
